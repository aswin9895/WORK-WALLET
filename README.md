# Work & Wallet

Offline Android app (React Native CLI, JavaScript, SCSS, SQLite) for keeping
catering work records: caterings → work days → people × rates, plus extras
like petrol. It produces a payment report per catering.

```bash
npm install
npm start          # Metro
npm run android    # install on phone/emulator
```
